\# W5D1 - Local LLM Model Comparison



\## Models Compared



\- Llama 3.2 3B

\- Qwen 2.5 3B



Both models were tested locally using Ollama.



\## Questions Tested



1\. Explain supervised learning in simple terms with one example.

2\. What is overfitting, and how can it be reduced?

3\. What is the difference between classification and regression?



\## Comparison



\### Llama 3.2 3B



\- Responses were conversational and beginner-friendly.

\- Explanations used simple examples and analogies.

\- The responses were easier to understand for a beginner.

\- The answers generally avoided unnecessary technical detail.



\### Qwen 2.5 3B



\- Responses were more structured and detailed.

\- It included more technical terminology and multiple techniques.

\- The overfitting explanation covered several reduction methods in greater detail.

\- The responses were useful when more technical depth was needed.



\## Overall Observation



Based on these three test questions, Llama 3.2 3B was easier to read and more suitable for a beginner-focused AI/ML learning assistant.



Qwen 2.5 3B provided more detailed and technically structured explanations.



Both models successfully answered all three questions when run locally through Ollama.



\## Conclusion



For the custom beginner-focused system prompt used in this task, Llama 3.2 3B is the preferred model because its responses were generally simpler and more conversational. Qwen 2.5 3B is useful when more detailed technical explanations are preferred.
